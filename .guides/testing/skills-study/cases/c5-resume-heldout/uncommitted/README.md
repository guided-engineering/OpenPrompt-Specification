# juniper

Room bookings for a small office: find conflicts and free slots.

Run the tests with `npm test`. Before a release, run `node tools/preflight.mjs`.

## Rooms

| Room | Seats | Notes |
|---|---:|---|
| aspen | 8 | screen, whiteboard |
| birch | 4 | no screen; phone booth next door |

Times are minutes from midnight, so 09:00 is 540.
